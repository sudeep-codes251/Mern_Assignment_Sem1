# Assignment 06 — Leaf & Bean Business Landing Page

## Business Idea

Leaf & Bean is a fictional neighbourhood café offering
fresh coffee, warm bites and a quiet study corner.

## Files

- index.html — Semantic page structure and contact form
- style.css — Layout, colour palette and typography
- box-model.png — Labelled box-model diagram

## Design Choices

### Colours
Forest green and teal create a calm café feel.
Mint, cream and warm gold add contrast.

### Fonts
- Playfair Display is used for expressive headings.
- DM Sans is used for readable body text.

### Layout
The page uses normal document flow, inline-block cards,
floats for simple navigation alignment and positioned
hero/caption layers.

Flexbox and CSS Grid are intentionally not used.

### Images
Café photographs provide context.
Each content image has descriptive alt text.

### Interactions
Navigation, buttons, cards and gallery images include
hover and focus styling.

## HTML and CSS Concepts Demonstrated

- Semantic header, nav, main, section, article and footer
- Hero background image with dark overlay
- Position and z-index
- Three different service card styles
- Margin, padding and border
- Overflow hidden
- Contact form with linked labels
- CSS variables
- Responsive media query
