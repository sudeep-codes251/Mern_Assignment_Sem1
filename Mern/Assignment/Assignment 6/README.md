# Assignment 07 — Flexbox Practice Pack

## Project Description

This project contains four separate HTML pages
that demonstrate one-dimensional layouts using CSS Flexbox.

## Files Included

1. menu.html
   - Horizontal navigation menu using Flexbox.

2. login.html
   - Login form centred horizontally and vertically.

3. products.html
   - Eight product cards using flex-wrap.

4. navbar-hero.html
   - Navigation bar and centred hero section.

5. style.css
   - Common external CSS stylesheet.

## Flexbox Properties Used

- display: flex
- justify-content
- align-items
- flex-direction
- flex-wrap
- gap
- flex-grow

## Other CSS Concepts

- CSS variables
- Hover effects
- Responsive design
- Border radius
- Box shadow
- Background images
- Media queries

## How to Run

1. Open the project folder in VS Code.
2. Install the Live Server extension.
3. Right-click any HTML file.
4. Select Open with Live Server.

## Design Choices

I selected dark green, teal, mint and gold
to create a clean campus-themed design.

The cards use rounded corners and subtle shadows
to make the product section attractive.

Flexbox provides consistent spacing and
responsive layouts across different screen sizes.
