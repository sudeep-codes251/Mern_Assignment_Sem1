
# Assignment 10 - Final Mini Project

## Project Name
Campus Collective

## About the Project
Campus Collective is a responsive student community landing page.
It encourages students to learn together, build projects, find mentors
and participate in campus activities.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Media Queries
- Google Fonts

## Project Structure
10-final-responsive-project/
- index.html
- style.css
- README.md

## Features
1. Responsive navigation bar
2. Hero section with call-to-action buttons
3. About section
4. Six feature cards
5. Image gallery
6. Contact form
7. Responsive footer

## CSS Concepts Used

### Flexbox
- Navbar alignment
- Hero content
- Button arrangement
- Contact form
- Footer links

### CSS Grid
- About section
- Services cards
- Image gallery
- Contact layout

### Responsive Design
- Tablet breakpoint: 900px
- Mobile breakpoint: 600px

## Design Choices
I selected dark teal, light green, white and golden yellow
to create a clean and modern campus theme.

Poppins is used for headings because it gives the website
a bold appearance. DM Sans is used for body text because
it is easy to read.
