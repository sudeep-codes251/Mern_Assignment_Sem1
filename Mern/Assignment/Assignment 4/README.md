
# Assignment 05 - Styled Portfolio

## Project Overview

This is my personal portfolio website created using HTML
and CSS. It showcases my introduction, skills, education,
projects and contact information.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- CSS Variables
- Flexbox and CSS Grid

## Design Choices

### 1. Fonts
I used Poppins for headings because it looks modern
and attractive. Roboto is used for body text because
it is simple and easy to read.

### 2. Colours
I selected a teal, dark green, white and light grey
colour palette to give the website a clean and
professional appearance.

### 3. Layout
I used Flexbox for navigation and the hero section.
CSS Grid is used to arrange project cards.

### 4. Hover Effects
I added hover effects to navigation links,
buttons, skill tags and project cards to make
the website more interactive.

### 5. Responsive Design
I used media queries to make the portfolio
work on mobile devices and desktop screens.
