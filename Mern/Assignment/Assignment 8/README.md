
# Assignment 09 — Responsive Audit

## Project Name
Leaf & Bean Cafe

## Objective
To make an existing website responsive on desktop,
tablet and mobile screens using CSS media queries.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- Media Queries
- Google Fonts

## Project Files

- index.html
- style.css
- cafe-scene.svg
- audit.md

## Responsive Breakpoints

- Desktop: 1200px
- Tablet: 768px
- Mobile: 375px

## Features

1. Responsive navigation bar.
2. Hero section with background image.
3. About section.
4. Three service cards.
5. Contact form.
6. Responsive footer.
7. Mobile-friendly layout.
8. Hover effects.
9. CSS variables.

## Design Choices

Forest green and teal are used to create a
natural cafe identity.

Mint and cream provide a soft background.
Playfair Display is used for headings and
DM Sans is used for readable body text.

## How to Run

1. Open the folder in VS Code.
2. Open index.html.
3. Right-click and select Open with Live Server.
4. Test using Chrome DevTools.
