
# Assignment 08 - Grid Practice Pack

## Project Description

This project demonstrates CSS Grid through three different web pages.

## Pages Included

### 1. gallery.html
- Photo gallery with 9 images.
- Uses display: grid.
- Three-column layout.
- Image hover effects.

### 2. product-grid.html
- Campus store product listing.
- Eight product cards.
- Uses repeat(auto-fit, minmax(200px, 1fr)).
- Automatically adjusts columns.

### 3. dashboard.html
- Student learning dashboard.
- Header, sidebar, main and footer.
- Uses named grid areas.

## CSS Concepts Used

- display: grid
- grid-template-columns
- grid-template-rows
- grid-template-areas
- grid-area
- gap
- fr units
- repeat()
- minmax()
- auto-fit
- Media queries

## Design Choices

I used dark teal, mint green, white and light blue-grey
for a clean and modern campus-themed appearance.

CSS Grid provides structured two-dimensional layouts.
Hover effects improve the appearance of cards and images.
Media queries make the pages responsive.

## How to Run

1. Open the folder in VS Code.
2. Install Live Server.
3. Right-click gallery.html.
4. Select Open with Live Server.
5. Open the other HTML pages to test them.
